# Care Overview Design Notes

## Purpose

Care Overview is designed to be a simple patient portal dashboard. It helps users find important information without opening several separate pages.

## Main Users

The main users are patients reviewing their own records. The interface should also be understandable for caregivers or staff who need a quick overview.

## Layout

The dashboard includes:

- Patient selection
- Recent visit information
- Upcoming appointments
- Follow-up tasks
- Messages
- Test results
- Medications
- Referrals and notifications

The most important information appears near the top of the page so users can quickly see what needs attention.

## Visual Style

The design uses:

- A simple healthcare color palette
- Clear headings and labels
- Cards and lists for related information
- Consistent spacing
- Readable text
- Buttons that clearly show available actions

The design avoids unnecessary decoration so the records remain the focus.

## Interaction

Users can select a patient, open different sections, and update certain records. After an update, the dashboard refreshes so the counts and statuses reflect the current database information.

## Accessibility and Scope

The application uses visible labels, clear status text, empty states, and keyboard-friendly controls where possible.
This is a fictional school project. It does not connect to real medical records or provide medical advice.
